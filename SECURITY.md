# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, contact the maintainer directly with:

* Description of the vulnerability
* Steps to reproduce
* Potential impact
* Suggested mitigation (if available)

I will acknowledge reports as soon as possible and work toward a resolution.

## Supported Versions

The latest version of repo-analyzer receives security updates and fixes.

## Disclosure Policy

Security issues will be investigated privately before public disclosure to protect users and downstream projects.
